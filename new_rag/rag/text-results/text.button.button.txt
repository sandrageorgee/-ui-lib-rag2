Component: button
============================================================

Interface: IButtonProps

Description:
Interface for the Button component. Extends all native HTML button attributes so consumers can pass onClick, disabled, type, aria-*, data-* and any other standard button prop.

Dependencies: IButtonProps

Allows additional props: False

------------------------------------------------------------

Extends: React.ButtonHTMLAttributes<HTMLButtonElement>
Note: IButtonProps inherits all props from React.ButtonHTMLAttributes<HTMLButtonElement>. Only the props declared directly on IButtonProps are listed below.

Default Values:
  variant: primary
  size: md
  loading: false

CSS Classes:
  - Cui-Button
  - Cui-Button__label
  - Cui-Button__leftIcon
  - Cui-Button__rightIcon
  - Cui-Button__spinner

Import:
  import { Button } from '@common-ui';

Demo Examples:

  --- Default ---

  () => (
    <div style={{ display: 'flex', gap: 12, padding: 40 }}>
      <Button label="Primary" variant="primary" />
      <Button label="Secondary" variant="secondary" />
      <Button label="Ghost" variant="ghost" />
      <Button label="Danger" variant="danger" />
    </div>
  )


  --- Sizes ---

  () => (
    <div style={{ display: 'flex', gap: 12, alignItems: 'center', padding: 40 }}>
      <Button label="Small" size="sm" />
      <Button label="Medium" size="md" />
      <Button label="Large" size="lg" />
    </div>
  )


  --- Loading ---

  () => {
    const [loading, setLoading] = React.useState(false);
  
    const handleClick = () => {
      setLoading(true);
      setTimeout(() => setLoading(false), 2000);
    };
  
    return (
      <div style={{ padding: 40 }}>
        <Button
          label={loading ? 'Saving...' : 'Save'}
          loading={loading}
          onClick={handleClick}
        />
      </div>
    );
  }


  --- Disabled ---

  () => (
    <div style={{ display: 'flex', gap: 12, padding: 40 }}>
      <Button label="Disabled Primary" variant="primary" disabled />
      <Button label="Disabled Secondary" variant="secondary" disabled />
    </div>
  )
