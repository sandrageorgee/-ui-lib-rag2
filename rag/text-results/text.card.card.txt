Component: card
============================================================

Interface: ICard

Description:
Interface for the Card component. A generic surface container used to group related content.

Dependencies: ICard

Allows additional props: False

------------------------------------------------------------

Extends: React.HTMLAttributes<HTMLDivElement>
Note: ICard inherits all props from React.HTMLAttributes<HTMLDivElement>. Only the props declared directly on ICard are listed below.

CSS Classes:
  - Cui-Card__helperIcon
  - Cui-Card__wrapper

Import:
  import { Card } from '@common-ui';

Demo Examples:

  --- Default ---

  () => {
    return (
      <div style={{ padding: 40, backgroundColor: '#f5f5f5', minHeight: '100vh' }}>
        <Card>
          <h3 style={{ margin: '0 0 8px' }}>Basic Card</h3>
          <p style={{ margin: 0 }}>This is the default card with no extra props.</p>
        </Card>
      </div>
    );
  }


  --- With Helper Icon ---

  () => {
    return (
      <div style={{ padding: 40, backgroundColor: '#f5f5f5', minHeight: '100vh' }}>
        <Card
          hasHelperIcon
          helperIcon="?"
          onClickHelperFunction={() => alert('Helper icon clicked!')}
          style={{ maxWidth: 320 }}
        >
          <h3 style={{ margin: '0 0 8px' }}>Card with Helper Icon</h3>
          <p style={{ margin: 0 }}>
            A small helper icon appears at the bottom-right corner of this card.
            Click it to trigger an action.
          </p>
        </Card>
      </div>
    );
  }
